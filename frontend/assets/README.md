# Frontend Assets

This directory contains the required assets for the React Native app.

## Required Files:

- `icon.png` - App icon (1024x1024 recommended)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon foreground
- `favicon.png` - Web favicon

## Generating Assets:

You can use online tools or design software to create these assets:

1. **App Icon (icon.png)**
   - Size: 1024x1024 pixels
   - Format: PNG with transparency
   - Should represent your budget app (e.g., dollar sign, calculator, piggy bank)

2. **Splash Screen (splash.png)**
   - Size: 1284x2778 pixels (iPhone 13 Pro Max)
   - Format: PNG
   - Should match your app's branding

3. **Adaptive Icon (adaptive-icon.png)**
   - Size: 1024x1024 pixels
   - Format: PNG with transparency
   - Android adaptive icon foreground layer

4. **Favicon (favicon.png)**
   - Size: 32x32 or 64x64 pixels
   - Format: PNG
   - For web version of the app

## Placeholder Assets:

For development, you can create simple colored squares:
- Use any image editor or online tool
- Create solid color images in the required dimensions
- Replace with proper designs before deployment

## Asset Optimization:

Before deployment:
- Optimize PNG files for smaller file sizes
- Ensure proper aspect ratios
- Test on multiple devices and screen sizes
